
# University Services App

## 1. Project Concept

A mobile application designed to provide university students with an easy and centralized way to access essential university services.

## 2. Problem Statement
- University services are distributed across different platforms.
- Students may struggle to access university announcements and information.
- Managing attendance, trips, and university services can be inconvenient.

## 3. Proposed Solution
A Flutter mobile application that brings multiple university services together in one platform.

## 4. Target Audience
- University Students
- University Administrators
- University Service Providers

## 5. Main Features
- Student Attendance Management
- University News and Announcements
- University Restaurant Ordering
- University Trips Booking
- University Fees and Payments

## 6. Tech Stack

### Frontend
- Flutter
- Dart

### Backend & Cloud
- AWS
- REST APIs
- SQL Server (Database during development)
